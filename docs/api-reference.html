API Reference — RadioE45

Elenco completo delle chiamate REST verso il backend AzuraCast usate dall'app .NET MAUI, con schema delle risposte JSON, riferimento al codice sorgente e link alla documentazione ufficiale. Documento di supporto per la riscrittura in HTML + JavaScript.

Backend: tutte le API sono esposte dall'istanza AzuraCast di ciascuna stazione radio, non da un server proprio di RadioE45. Non è richiesta autenticazione: sono tutti endpoint pubblici in GET. L'URL base di ogni chiamata è ricavato dal campo UrlBase della stazione (es. 192.168.1.68), a cui viene anteposto https:// se lo schema non è già presente (UrlBaseHelper.EnsureScheme). Gli esempi di questo documento sono presi da una chiamata reale all'istanza AzuraCast di test Radio CyberFranchetti (http://192.168.1.68, stationId = 1).

GET /api/nowplaying/{stationId}?_={cacheBust}

Now Playing — brano corrente, prossimo, ascoltatori, stato live

Interrogato ogni 10 secondi mentre l'utente ascolta una stazione, per aggiornare titolo/artista/copertina, conteggio ascoltatori e stato "in diretta con DJ".

ParametroTipoNote
stationIdint (path)ID numerico della stazione su AzuraCast
_long (query)Timestamp Unix in millisecondi, usato solo per invalidare la cache HTTP/CDN (cache-busting), non ha effetto sul contenuto

Esempio URL completo

GET http://192.168.1.68/api/nowplaying/1?_=1789221471000

Risposta JSON reale (campi usati dall'app)

    "id": 1,
    "name": "Radio CyberFranchetti",
    "listen_url": "http://192.168.1.68/listen/radio_cyberfranchetti/radio.mp3"
  },
  "now_playing": {
    "song": {
      "id": "c983f6da8bee266f0613e3a564d8e88f",
      "text": "Bruce Springsteen - I'm Goin' Down",
      "artist": "Bruce Springsteen",
      "title": "I'm Goin' Down",
      "art": "http://192.168.1.68/api/station/radio_cyberfranchetti/art/969616fb0f6f233086f88805-1788546255.jpg"
    },
    "played_at": 1789221471,
    "duration": 258,
    "elapsed": 11
  },
  "playing_next": {
    "song": {
      "id": "25b0db2b165ac4f84ca41055806c6885",
      "text": "The Wallflowers - One Headlight",
      "artist": "The Wallflowers",

Nota: se now_playing.song.title contiene "jingle" (case-insensitive), l'app tratta il brano come jingle e mostra nome/logo della stazione al posto di artista/titolo/copertina.

ParametroTipoNote

  "id": 1,
  "name": "Radio CyberFranchetti",
  "shortcode": "radio_cyberfranchetti",
  "description": "I più grandi successi Rock e Pop",
  "listen_url": "http://192.168.1.68/listen/radio_cyberfranchetti/radio.mp3",

Episodi di un podcast

Usato quando l'utente apre un podcast per vedere/riprodurre i singoli episodi.

ParametroTipoNote
stationIdint (path)ID numerico della stazione
podcastIdstring (path)ID alfanumerico del podcast (campo id della risposta podcast)

Esempio URL completo

GET http://192.168.1.68/api/station/1/public/podcast/1f1aaa41-2d73-6fc6-881f-fd584083348f/episodes

Risposta JSON reale (array, campi usati dall'app)

[
  {
    "id": "1f1ab796-7900-6b26-91dc-cd6b110968ff",
    "title": "Da 4.000 a 74.000 attacchi esplorativi in pochi giorni",
    "description": "Cybersecurity",
    "season_number": 1,
    "episode_number": 2,
    "publish_at": 1788867334,
    "art": "http://192.168.1.68/api/station/radio_cyberfranchetti/public/podcast/1f1aaa41-2d73-6fc6-881f-fd584083348f/episode/1f1ab796-7900-6b26-91dc-cd6b110968ff/art",
    "has_media": true,
    "media": {
      "length": 835,
      "length_text": "13:55"
    },
    "links": {
      "download": "http://192.168.1.68/api/station/radio_cyberfranchetti/public/podcast/1f1aaa41-2d73-6fc6-881f-fd584083348f/episode/1f1ab796-7900-6b26-91dc-cd6b110968ff/download.mp3"
    }
  }
]
Attenzione, importante per chi riscrive il client: l'URL di streaming/download reale dell'episodio va sempre preso da links.download (già assoluto e risolto correttamente dal server). Non va mai ricostruito a mano — un path come /podcast/{id}/episode/{id}/media non coincide con quello pubblico reale (/public/podcast/{id}/episode/{id}/download.mp3) e viene rifiutato dal server. Vedi commento in AzuraCastPodcastEpisode.cs.

Il client filtra e ordina lato app: tiene solo gli episodi con has_media: true e links.download non vuoto, poi ordina per publish_at decrescente (più recenti prima).

Contesto: stream audio diretto (non-JSON)

Oltre alle API JSON sopra, l'app riproduce l'audio collegandosi direttamente allo stream della stazione — non è una chiamata REST che restituisce JSON, ma una connessione HTTP persistente al player (MediaElement / ExoPlayer / AVPlayer a seconda della piattaforma):

FormatoSorgente URLNote
Diretto (Icecast/MP3){UrlBase}{StreamUrl}, es. http://192.168.1.68/listen/radio_cyberfranchetti/radio.mp3Preferito di default (PreferHlsStream = false); nessun concetto di "live edge", buffer fino a ~50s
HLScampo hls_url restituito da dettaglio stazione / elenco stazioniOpzionale, attivabile da impostazioni; introduce alcuni secondi di latenza aggiuntiva per via della segmentazione HLS

La scelta tra i due candidati avviene lato app tramite StreamUrlProber, che prova gli URL in ordine di priorità (non in parallelo) e usa il primo raggiungibile.

Contesto: campo WebSocket (presente ma non usato)

Ogni stazione ha un campo WebsocketUrl (es. /api/live/nowplaying/websocket, che AzuraCast espone su wss://) salvato nel modello dati e nel DB locale, ma non è mai aperto/consumato da nessun servizio dell'app. L'aggiornamento del "now playing" avviene solo tramite polling REST ogni 10 secondi sull'endpoint Now Playing. Chi implementa la versione HTML+JS può ignorare questo campo, oppure valutare di sostituire il polling con una vera connessione WebSocket per ridurre la latenza (AzuraCast la supporta nativamente).
